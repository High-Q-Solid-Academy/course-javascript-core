# ⚡ JavaScript Core & DOM — High Q Solid Academy

Welcome to **JavaScript Core & DOM** at **High Q Solid Academy**. JavaScript is the dynamic programming language that powers modern interactive web applications.

---

## 🎯 What You Will Master
- Core syntax: `let`/`const`, data types, operators, conditionals, and functions
- Modern ES6+: Arrow functions, template literals, destructuring, and spread/rest syntax
- High-Order Array methods: `map()`, `filter()`, `reduce()`, and `find()`
- Object manipulation, nested structures, and JSON handling
- DOM Manipulation: Selecting elements, creating dynamic nodes, and handling user events
- Asynchronous JavaScript: Promises, `async`/`await`, Fetch API, and error handling
- Writing clean, modular, test-driven JavaScript code

## 🚀 How to Complete Exercises & Get Graded

1. Clone this repository locally.
2. Install testing dependencies:
   ```bash
   npm install
   ```
3. Open the exercise files and implement the requested functions.
4. Test your logic locally in real time:
   ```bash
   npm test
   ```
5. Push your completed work to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete javascript core exercises"
   git push origin main
   ```
6. GitHub Actions will execute the test suite and verify your code!
