# Exercise 1: JavaScript Fundamentals & Functions

## 🎯 Objective
Write pure functions handling basic arithmetic, conditionals, and string transformations.

## 📋 Requirements
Inside `math-utils.js`, implement and export the following functions:

1. `calculateAverage(scores)`:
   - Takes an array of numbers.
   - Returns the average. If the array is empty, return `0`.
2. `isPassingGrade(score)`:
   - Returns `true` if `score >= 50`, otherwise returns `false`.
3. `formatStudentName(firstName, lastName)`:
   - Returns a formatted string: `"LastName, FirstName"` in uppercase, e.g. `"ADEBULE, QUAM"`.
